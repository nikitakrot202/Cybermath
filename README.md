# CyberMath — Gamified Mathematics Learning Platform

**Diploma project · Three-person team**

CyberMath is a web-based, gamified mathematics learning project developed during my software development studies.

## Features
- User registration and authentication
- Mathematics topics and practice tasks
- Coins, leaderboard and progress tracking
- Administration and moderation functionality

## Tech stack
PHP, MySQL/MariaDB, JavaScript, HTML/CSS, Bootstrap. The project has also been deployed with Linux, nginx and PHP-FPM.

## My contribution
I worked on **frontend and backend development**, together with another programming teammate. A third teammate contributed design concepts and ideas. This is a **team diploma project**, not a solo application.

## How to run locally
> **Source code has not yet been uploaded to this repository.** This section will be expanded with verified installation steps when a clean project archive is available.

The original application uses PHP and MySQL/MariaDB. It requires application files, a sanitized database schema, a local web server and environment-specific configuration. Production credentials and real user data must never be committed.
